# B-Atlas v6.76.0 — Page Consistency, Watchlist & Transfer Guidance

## Boat Guide / Buy
- Added Create Watchlist to the Buy section. It opens the existing Boat Watch workflow with the current model preselected.
- Corrected Add Listing to use white text on the primary blue action.

## Boat family icons
- Replaced the Sportfisher asset with the user-approved right-facing reference supplied for this release.

## Saved Models / Compare
- Restyled the Saved Models page title to match primary B-Atlas page headings.
- Standardized top-level page content geometry to a centered 1360 px maximum width with consistent side gutters.
- Corrected Compare Models so its content begins below the fixed site header and uses the shared page width.

## Move / Share
- Renamed the transfer choice to “Move to another device or browser.”
- Added explicit instructions: copy the link, open it in the destination browser/device, review the incoming models, then Merge or Replace.
- Clarified that Chrome, Edge, Firefox and other browsers can be destinations.
- Expanded privacy language to explain the URL-fragment approach and the need to treat a transfer link as private.

## About / Privacy
- Added Boat Watch and cross-device/cross-browser Saved Models portability to About.
- Added a privacy-by-design explanation of local browser storage and deliberate transfer links.
- Updated Privacy copy so it no longer incorrectly suggests that changing browsers necessarily loses Saved Models.

## Version
- Updated visible site version to v6.76.0.
