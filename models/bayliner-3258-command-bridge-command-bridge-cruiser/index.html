Bayliner 3258 Command Bridge Command Bridge Cruiser

1995–2000

The Bayliner 3258 Ciera Command Bridge is a twin-sterndrive flybridge cruiser with an 11-foot beam and family-oriented cabin arrangement. Factory documentation confirms substantial tankage and a roughly 33-foot overall length; gasoline and diesel twin-engine packages were offered.

Inspection focus
